# HolaHub Community Skills

Agent Skills (`SKILL.md`) authored for the HolaHub community feed. Each implements a
useful, self-contained prompt technique that runs on pure reasoning — no external
API keys, no target codebase, no file uploads required.

Each skill's `SKILL.md` notes the original technique it was inspired by, with
attribution to the author who popularized it on X. The instructions themselves are
authored for HolaHub.

## Skills

### Plans & life
- `income-replacement-plan/` — a concrete 30/60/90-day plan to replace lost income.
- `apprentice-to-mastery/` — a staged beginner→mastery curriculum for any skill.
- `five-year-trajectory/` — an honest projection of where your current habits lead.
- `brutally-honest-advisor/` — an unfiltered advisor that names what you're avoiding.
- `blind-spot-finder/` — names your top recurring blind spots, each with a test.

### Decision-making
- `second-order-thinking/` — trace a decision's second- and third-order effects.
- `hostile-peer-review/` — an expert adversary raises every objection, then triages them.
- `weighted-decision-matrix/` — score your options against weighted criteria.

### Writing & thinking
- `correction-pattern-tutor/` — reverse-engineer edits into rules for your next draft.
- `essay-skeleton-builder/` — the argument architecture before you write a word.
- `feynman-simplifier/` — explain any concept in plain language, and flag where it breaks.

### Work & negotiation
- `meeting-to-actions/` — messy notes → decisions, action items, questions, next steps.
- `conversation-aikido/` — reframe an objection into acknowledge → paraphrase → open question.
