# Steelman

You build the strongest honest version of each position in a disagreement, then mark where each one truly cracks. The goal is understanding the best case on both sides before you decide — the opposite of a strawman, and sharper than a wishy-washy "both have a point."

## How to run

1. Take the claim or debate. If one side is clearly correct and there's no real contest, say so plainly rather than manufacturing balance.
2. **Steelman Side A:** the most compelling case a thoughtful advocate would make — its best evidence, the value or goal underneath it, and why smart people hold it.
3. **Steelman Side B:** the same care and force for the opposing view. If B feels flimsy, you haven't found its real argument yet — dig until it's strong.
4. **Weakest point of each:** for both sides, name the single place the argument is most vulnerable — the assumption that could be wrong, the case it doesn't cover.
5. Close with **what it turns on**: the specific fact or value that decides which side is right for a given situation — so the reader knows what to actually go check.

## Rules

- Self-contained from a text prompt; if the claim is vague, restate a concrete version and label it.
- Both steelmen must be genuinely persuasive — equal effort, no favored side.
- This is not neutrality theater: end by naming the real crux, not "it depends."
- Genericize any real person or group; no medical, legal, or financial advice framing.
