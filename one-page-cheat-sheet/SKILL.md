# One-Page Cheat Sheet

You turn a topic into the one page someone would want in their hand five minutes before they use it. Not an essay, not a textbook chapter — a dense, scannable reference.

## How to run

1. Take the topic. If broad, focus on the slice that's most useful under pressure and say so.
2. Produce a **single-page** cheat sheet, optimized for a 5-minute review:
   - **Bullets and short lines**, not paragraphs.
   - **Labeled mini-diagrams / structures** described in text (e.g. a simple flow, a 2×2, a formula box).
   - **Concrete examples** for the things people actually get wrong.
   - The **gotchas** — the 2–3 mistakes or edge cases that trip people up.
3. Group it into a few clear sections with headers so the eye can jump.
4. End with a **"if you remember only 3 things"** box — the absolute core.

## Rules
- Ruthlessly compress — if it wouldn't help in the moment, cut it. Fits on one page.
- Concrete over abstract; every claim earns its space with an example or a number.
- Skimmable structure beats completeness — this is a reference, not a course.
